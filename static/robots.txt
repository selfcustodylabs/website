# NOTHING is Disallowed here, deliberately.
#
# Every page we want kept out of the index instead emits
# <meta name="robots" content="noindex, follow"> so Google can crawl it, read
# the directive, and drop it cleanly under "Excluded by noindex".
#
# A Disallow does the opposite: it stops the crawl, so Google never sees the
# noindex and the URL sits in "Blocked by robots.txt" indefinitely. That is
# exactly what happened to /docs/tags/* before commit f4329fc9.
#
# The noindex is emitted by:
#   src/theme/DocTagsListPage    -> /docs/tags/
#   src/theme/DocTagDocListPage  -> /docs/tags/*
#   src/theme/SearchPage         -> /search/  (wrapper; upstream emits an
#                                  invalid property="robots" that Google ignores)
#   src/pages/404.js             -> /404/
#
# These paths are also excluded from the sitemap via sitemap.ignorePatterns
# in docusaurus.config.js. Keep the two lists in sync.

# change: it is the section an AI-policy audit reads, and it survives any future
# edit to the * group.
#
# READ THIS BEFORE EDITING THE * GROUP ABOVE:
# robots.txt matching is most-specific-group-wins. A crawler that finds a group
# naming itself reads ONLY that group and ignores User-agent: * entirely. So any
# rule added to the * group from now on does NOT apply to the bots listed below
# unless it is repeated inside each of their groups.
#
# The three functional classes, which are worth keeping straight:
#   training  - feeds model training corpora (GPTBot, ClaudeBot, CCBot, Google-Extended)
#   search    - builds the retrieval index an assistant cites from
#               (OAI-SearchBot, Claude-SearchBot, PerplexityBot)
#   user      - fetches a page live when a person asks about it
#               (ChatGPT-User, Claude-User, Perplexity-User)
#
# All three are allowed. The content is public Bitcoin education: being in the
# training corpus is how a model learns to recommend SeedSigner and warn about
# the 2026 Coldcard entropy incident even in answers that cite nobody.
