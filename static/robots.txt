# NOTHING is Disallowed here, deliberately.
#
# Every page we want kept out of the index instead emits
# <meta name="robots" content="noindex, follow"> so Google can crawl it, read
# the directive, and drop it cleanly under "Excluded by noindex".
#
# A Disallow does the opposite: it stops the crawl, so Google never sees the
# noindex and the URL sits in "Blocked by robots.txt" indefinitely. That is
# exactly what happened to /docs/tags/* before commit f4329fc9.
#
# The noindex is emitted by:
#   src/theme/DocTagsListPage    -> /docs/tags/
#   src/theme/DocTagDocListPage  -> /docs/tags/*
#   src/theme/SearchPage         -> /search/  (wrapper; upstream emits an
#                                  invalid property="robots" that Google ignores)
#   src/pages/404.js             -> /404/
#
# These paths are also excluded from the sitemap via sitemap.ignorePatterns
# in docusaurus.config.js. Keep the two lists in sync.
