Libreboot BIOS

Libreboot is free, open-source boot firmware for computers, built on coreboot, that replaces the laptop's proprietary BIOS or UEFI. This guide installs it on a Lenovo ThinkPad (the X230, T420, T430, T440p, T480s, T530 or W530) using a Raspberry Pi Pico as an external programmer: build Libreboot and the Pico's firmware from source, clip the Pico onto the laptop's flash chip, back up the original firmware, and write the new image. It takes three to five hours and about $15 to $30 of parts, and gives a Bitcoin computer or air-gapped computer firmware whose source you can read.

What does Libreboot change, and what doesn't it?​

Libreboot replaces the vendor firmware that starts the computer with open-source code, and it reduces, but does not eliminate, Intel's proprietary code. Since 2022 it follows what it calls a binary blob reduction policy: a board gets the vendor code it cannot boot without, and nothing more.

Lenovo firmwareLibreboot
Firmware sourceClosedOpen (coreboot, plus Libreboot's build system)
Intel Management Engine (ME)Fully enabledCut down with me_cleaner and disabled; it cannot be removed entirely on these machines
Intel Boot Guard (T480s)Enforced: only Lenovo-signed firmware runsDisabled with deguard
Other vendor codeBuilt inOnly what the board needs to boot, such as CPU microcode and memory set-up code on some models
Boot menuLenovo'sEDK2 (UEFI), with SeaBIOS and GRUB available

The Intel Management Engine is a separate processor inside Intel chipsets, running its own closed firmware with access to memory and the network, that operates independently of the operating system. On every ThinkPad in this guide the CPU will not run without part of its firmware, so Libreboot cannot remove it. It uses me_cleaner to strip the ME firmware to the minimum needed to start the machine and to switch it off after that. The ME is removed completely only on older boards such as the ThinkPad X200 and T400. None of the laptops here use AMD processors, so AMD's equivalent (the PSP) does not arise.

What this buys a Bitcoin computer is firmware you can audit and rebuild yourself, a much smaller body of closed code running before your operating system, and no vendor update channel that could change it underneath you. It does not make the hardware free of all closed code, and Libreboot's own documentation says so.

What changed in Libreboot 26.10?​

Libreboot 26.10 "Ominous Olive", released on 15 October 2026, made EDK2, an open-source UEFI implementation, the default payload on most boards, with SeaBIOS and GRUB still available. Board targets now carry the vendor's name (lenovo_thinkpad_t480s_16mb rather than t480s_16mb), and image names start with uefi_ or bios_. The build and ROM pages of this guide use the 26.10 names. If you are updating a machine flashed with an older release, see update Libreboot.
