Advanced setup guides

The advanced guides address specific threats that a single, well-kept hardware wallet does not: multisig removes single points of failure, inheritance planning makes sure your bitcoin outlives you, an air-gapped computer signs and generates seeds with no network at all, a dedicated bitcoin computer keeps wallet software away from your everyday browsing, and open-source firmware replaces the code that runs before the operating system. Most people do not need them; they assume you already have a working hardware wallet, a tested backup and the basics from Learn and wallet setup. Match them to your threat model.

Which advanced setup protects against what?​

SetupProtects againstEffortWho needs it
MultisigSingle points of failure, a compromised deviceHighLarge holdings, inheritance plans
Inheritance planningYour bitcoin being lost when you dieMediumAnyone with bitcoin to pass on
Air-gapped computerNetwork attacks and malware reaching your keysMediumDice seed generation, offline signing
Bitcoin computerCompromise through everyday devicesMediumPrivacy-minded users
Libreboot or corebootProprietary firmware, including Intel's Management EngineVery highThe highest security requirements

What does each guide involve?​

GuideTimeCostWhat it covers
Multisig4-8 hoursAbout $200-750Choosing a quorum, preparing three hardware wallets, building the wallet in Sparrow, backup and recovery
Inheritance planning2-4 hoursVariesWhy bitcoin inheritance differs, approaches from simple to multisig, legal points, common mistakes
Air-gapped computer2-4 hours$50-200, or free with an old laptopChoosing hardware, removing network cards, Libreboot, an encrypted Linux install, offline software
Bitcoin computer1-2 hours$50-150, or free with repurposed hardwareA computer used only for bitcoin; unlike an air-gapped one it connects, to run a node or broadcast
Libreboot3-5 hours$15-30 of flashing hardwareOpen-source firmware on supported ThinkPads, with the Intel ME stripped and disabled
Coreboot2-4 hours$0-30Open-source firmware on more machines, with some proprietary code retained

In what order should you build them?​

StageSteps
1. FoundationA hardware wallet, a verified backup, your own node
2. Stronger securityA dedicated bitcoin computer, operational and physical security, inheritance planning
3. Advanced protectionAn air-gapped computer, a seed made with dice
4. Maximum securityMultisig, open firmware

If you want to remove single points of failure, start with a 2-of-3 multisig. If you want your family to inherit your bitcoin, start with inheritance planning. To generate your own seed securely, combine an air-gapped computer with the dice guide.

Common questions​

Is multisig worth the complexity?​

For life-changing amounts, yes: removing single points of failure is worth the extra work. For smaller amounts, a well-kept single-signature setup is enough.

Can you use an old laptop as an air-gapped computer?​

Yes; old laptops are ideal. Remove the Wi-Fi and Bluetooth cards rather than only disabling them in software. See removing the network hardware.

Do you need open-source firmware?​

Most people do not: a good hardware wallet used well is strong security. Open firmware suits extreme threat models and people who want to be able to inspect everything. Open source is not a guarantee, though: in the 2026 Coldcard incident the bug sat in public code for five years. Openness makes verification possible; someone still has to do it.

Should you choose a secure element or open source?​

You no longer have to choose. Secure elements resist physical extraction and open source allows auditing, and the Trezor Safe 7 pairs open firmware with an auditable secure element, while the BitBox02 Nova and Passport Prime combine certified chips with fully open code.
