Wallet setup guides

Setting up self-custody takes three guides, done in order: set up a hardware wallet, verify that the backup restores it, then work through the before you deposit checklist. Together they take two to three hours, and nothing significant should go into the wallet until all three are done. If bitcoin itself is new to you, read Start here first.

What does each guide cover?​

GuideTimeWhat it coversDo it after
Hardware wallet setup1-2 hoursBuying and checking the device, firmware and PIN, a seed made with your own dice, wallet software (Sparrow), checking a receive addressNothing: most people start here
Backup verification30-60 minutesRestoring the wallet from the written backup alone and comparing addresses, testing a passphrase, what to do if it failsHardware wallet setup
Before you deposit15-30 minutesThe final checks: seed, recovery test, passphrase, address on the device, genuine software, a test transactionBackup verification

If you already have a hardware wallet, start with backup verification.

The hardware wallet comparison covers every device and why Coldcard, Ledger and Bitkey are not on this list, and choose your setup matches a setup to how much you hold.

When is a software wallet enough?​

A software wallet keeps the keys on your phone or computer. It is free and convenient, and acceptable for amounts under about $1,000, for learning, and as a spending wallet alongside a hardware wallet for savings. It is not the place for significant savings or long-term holdings, because the keys sit on a device that also runs everything else.

What comes after setup?​

  1. Run your own node, so your wallet checks transactions itself.
  2. Learn UTXO management, for privacy and lower fees.
  3. Add a passphrase, as a second secret protecting the seed phrase.
  4. Move to multisig for larger holdings.

Common questions​

Do you need to buy a hardware wallet?​

For anything more than pocket money, yes. A hardware wallet is the minimum we recommend for any amount you would be upset to lose, because it keeps the keys off the computer and phone that malware can reach.

Which is better: Trezor, Ledger or Coldcard?​

As of October 2026, Trezor is the one of the three we recommend: open source, with a long security record. Coldcard is not currently recommended, because its 2026 entropy incident cost users about $116 million after a warning about the flaw had been dismissed. Ledger's secure element firmware is closed source, which means trusting what you cannot verify. Jade, BitBox02 Nova and Passport are also worth considering; the hardware wallet comparison covers them all.

Can you use the same seed on several devices?​

You can, but it is rarely a good idea: every device holding the seed is another place it can be stolen from, and none of them adds protection against losing it. If you want redundancy, multisig gives it without copying one seed around.

What if you already have a hardware wallet set up?​

Start with backup verification to confirm your existing backup restores the wallet, then work through the before you deposit checklist.
