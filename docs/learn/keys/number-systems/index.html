Number systems

Bitcoin keys are numbers, and the same number can be written in different bases: decimal (base 10) for people, binary (base 2) for the bits a seed is made of, and hexadecimal (base 16) for compact display of hashes and keys. The dice guide moves between all three, so this page covers just enough to follow it.

What is decimal?​

Decimal is base 10: each digit has ten possible values, 0 to 9. Counting past 9 adds a digit on the left and resets the right one to 0, giving 10. Each position is worth ten times the one to its right (ones, tens, hundreds).

What is binary?​

Binary is base 2: each digit, or bit, is 0 or 1. Counting goes 0, 1, 10, 11, 100, 101, 110, 111, 1000. Each position is worth twice the one to its right: 1, 2, 4, 8, 16 and so on, so 1011 is 8 + 0 + 2 + 1 = 11. A die roll in the dice guide becomes one bit, and 11 bits make one seed word, because 211 = 2048 is the length of the BIP39 word list.

What is hexadecimal?​

Hexadecimal is base 16: each digit has sixteen values, written 0 to 9 and then a to f for 10 to 15. One hex digit stands for exactly four bits, which makes it a compact way to write binary: 2047 is 11111111111 in binary (11 digits) but 7ff in hex. SHA-256 hashes, such as the one the dice guide uses for its checksum, are usually printed in hex.
