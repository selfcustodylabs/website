# CLAUDE.md — selfcustodylabs.com

Docusaurus 3.10 static site (Bitcoin self-custody guides), React 18, deployed to GitHub Pages
at https://selfcustodylabs.com. Content is Markdown/MDX in `docs/`; everything else is
presentation, navigation, and SEO plumbing.

This site is **SEO-load-bearing** — it earns its traffic from Google. A change that breaks a
URL, a redirect, or a meta tag is a bigger deal here than a visual regression. Read the SEO
invariants below before touching `docusaurus.config.js`, `sidebars.js`, or `src/theme/`.

## Commands

`npm` and `node` are nvm lazy-load shell functions that **do not resolve in non-interactive
shells** (`_load_nvm: command not found`, exit 127). Prefix every invocation with `command`:

```bash
command npm run start      # dev server on :3000
command npm run build      # production build — also the link checker (onBrokenLinks: "throw")
command npm run serve      # serve ./build locally
command npm run lint       # eslint src/
command npm run format     # prettier over src/
command npm run clear      # wipe .docusaurus cache when the build acts stale
```

`command npm run build` is the real gate: broken links throw, so a green build means links,
MDX, and swizzled components all resolve. Run it before claiming a content change is done.

## Adding or editing a doc

1. **Frontmatter is required** — `title`, `description`, `keywords`, `tags`, `sidebar_position`.
   Titles **≤60 chars**, descriptions **120–160 chars** (commit `87d10998` normalized these
   sitewide; don't regress them).
2. **Register it in [sidebars.js](sidebars.js)** unless it falls under an `autogenerated` category.
   Section index pages are real `index.md` / `README.md` files, not Docusaurus generated-index
   routes — that was a deliberate change (`60aa2862`) so the sitemap carries `lastmod`.
3. **Regenerate OG images** — `python3 scripts/generate-og-images.py` (needs Pillow + Noto fonts
   at `/usr/share/fonts/truetype/noto/`). It walks `docs/**/*.md`, writes `static/img/og/`, and
   rewrites `src/data/ogManifest.json`. All three counts must stay equal (currently 88/88/88);
   a doc missing from the manifest silently falls back to the generic social card.
4. **Optional per-path wiring**: multi-step guides → `src/data/progressData.js`; follow-up links
   → `src/data/nextStepsData.js`; structured data → `src/data/schema/*`.
5. **Renaming or deleting a URL requires a redirect** — see invariants below.

These MDX components are globally available with **no import** (registered in
[src/theme/MDXComponents/index.js](src/theme/MDXComponents/index.js)): `ProgressIndicator`,
`NextSteps`, `SectionBadge`, `RelatedArticles`, `FeaturedImage`. Anything else needs
`import { X } from '@site/src/components'`.

The OG script derives URLs **from file path, ignoring `slug:` frontmatter**. The 36 docs that
declare a `slug` currently all match their path — keep it that way or the manifest keys drift
off the real routes.

## SEO invariants — don't break these

- **Never add `index, follow` or a `googlebot` directive to `headTags`.** A global `index`
  overrode the per-page `noindex` on tag pages and stranded them in GSC "Crawled – currently not
  indexed" for months. `index`/`follow` are the defaults; keep only the `max-*-preview` values.
  There's a comment guarding this at [docusaurus.config.js:44](docusaurus.config.js#L44).
- **Tag pages are intentionally `noindex, follow`** (swizzled `DocTagsListPage` /
  `DocTagDocListPage`) and excluded from the sitemap. Don't re-enable tag indexing. Thin tags get
  **removed, not consolidated** — and the resulting `/docs/tags/*` 404s are correct, not bugs.
- **`trailingSlash: true`**, so `existingPath` inside `createRedirects()` arrives *with* a
  trailing slash. Any new `===` comparison must use the normalized `path` variable at the top of
  that function, or the redirect is silently never generated and the old URL 404s.
- **Every removed or renamed URL gets a redirect** in the `plugin-client-redirects` list. Before
  "fixing" an existing redirect, check it there first — the history is long and mostly deliberate
  (`/docs/basics/*`, `/docs/seed/*`, `/docs/privacy/*` etc. were all consolidated into
  `/docs/learn/*`).
- **Client redirects are meta-refresh pages returning HTTP 200**, not server 301s — GitHub Pages
  can't do path-level 301s. Old URLs scattering across GSC's "Page with redirect" *and*
  "Crawled – currently not indexed" is expected, not repo-fixable.

## Front-end conventions

- **Dark mode only** — `colorMode.disableSwitch: true`. Don't add light-theme variants.
- **Tailwind with `preflight: false`** (Infima owns the reset). Brand tokens live in
  [tailwind.config.js](tailwind.config.js): amber `#f59e0b`, `bg.*`, `ink.*`, `line.*`.
- **CSS load order** is `custom.css` → `base.css` → `theme/chrome.css` → `tables.css` →
  `utilities.css`; Infima selector overrides belong in `theme/chrome.css`, doc-markdown utility
  classes in `tables.css` / `utilities.css`.
- Functional components with hooks, JSDoc on props, ES6 imports grouped React → Docusaurus → MUI
  → local. See [CONTRIBUTING.md](CONTRIBUTING.md).
- **Raw HTML in `themeConfig` escapes the link checker.** `onBrokenLinks: "throw"` only walks
  Markdown/MDX, so hrefs inside `announcementBar.content`, `navbar`, and `footer` strings can 404
  on a green build. Verify those routes by hand (`curl -o /dev/null -w "%{http_code}"`).
- **The announcement bar is single-line by default.** Docusaurus pins
  `--docusaurus-announcement-bar-height` to `30px` at ≥997px; anything that wraps overflows the
  colored box and renders over the page. `theme/chrome.css` overrides it to `auto` — keep that if
  you edit `announcementBar.content`. Bumping its `id` re-shows the bar to everyone who dismissed
  it (dismissal is persisted in localStorage per `id`).

## Deploy & hosting boundaries

Push to `main` → [.github/workflows/deploy.yml](.github/workflows/deploy.yml) builds and pushes
`./build` to the `gh-pages` branch via `peaceiris/actions-gh-pages`. CI uses Node 23; `.nvmrc`
says 20; `engines` says >=18.

**Not fixable in this repo** — don't propose code changes for these:

- `http://` → `https://` — GitHub Pages "Enforce HTTPS" toggle
- `www.` → apex — derived from [static/CNAME](static/CNAME)
- DNS A/CNAME records — at the registrar
